# СберЗвук на ГУ Tank 300 — как пользоваться

**Версия приложения:** 1.2.2

Это приложение для прослушивания музыки сервиса **Звук** на штатном экране автомобиля. Ниже — только то, что нужно водителю или пассажиру, без технических подробностей.

## Что можно делать

- Искать треки, альбомы и исполнителей.
- Слушать **альбом целиком** или выбрать любой трек из альбома.
- Открыть **страницу исполнителя**: популярные треки, альбомы, отдельная кнопка «волна» по этому артисту.
- Настроить и запустить **персональную волну** в меню **«Волна»**: популярность, настроение (спокойное — энергичное, грустное — весёлое), жанры и язык.
- Смотреть **избранное** и запускать волну по избранным трекам кнопкой вверху списка.
- Открыть **очередь**: видно, что сейчас играет и что дальше, у каждого трека — длительность; список сам прокручивается к текущему треку; можно нажать на трек, чтобы перейти к нему.
- Включить **тёмную или светлую тему** (переключатель слева вверху).
- Управлять воспроизведением справа: пауза, следующий, предыдущий, перемотка (тап по **столбикам прогресса** — перейти к нужному месту в треке), лайк, **волна по текущему треку**.
- **Прогресс трека** — анимированные столбики по спектру звука (низкие частоты слева, высокие справа); на паузе столбики одинаковой высоты.
- Нажать на **обложку** текущего трека — откроется **полноэкранный режим** с анимацией звука на фоне обложки. Внизу остаются привычные кнопки и столбики прогресса. **Нажмите на область анимации**, чтобы вернуться к обычному виду. При смене трека рисунок анимации и цвета меняются сами.

## Как войти в аккаунт (токен)

Приложению нужен доступ к вашему аккаунту Звука. Это делается один раз (пока не смените токен).

1. На компьютере войдите на сайт **zvuk.com** под своим логином.
2. Откройте в браузере страницу профиля API: **[https://zvuk.com/api/tiny/profile](https://zvuk.com/api/tiny/profile)**  
   В ответе будет блок с данными профиля и полем **token** — длинная строка.
3. Скопируйте значение **token** (без кавычек).
4. В приложении нажмите кнопку **«Токен»** (справа от переключения темы), вставьте строку и нажмите **«Сохранить»**.

**Удобный способ на ГУ:** положите в файл одну строку — сам токен. В окне токена нажмите **«Выбрать...»** и укажите этот файл через системный диалог. Можно также положить файл с именем **zvuk_token.txt** по пути, который приложение показывает в том же окне; после перезапуска приложение само подхватит токен из файла.

Не передавайте токен посторонним: по нему можно пользоваться вашим аккаунтом.

## Полноэкранная анимация звука

1. Воспроизведите любой трек.
2. Нажмите на **картинку альбома** в правой панели плеера.
3. При первом открытии Android может спросить разрешение, связанное с визуализацией звука — **разрешите**, иначе анимация не заработает (микрофон приложение не использует).
4. Чтобы выйти — **нажмите на область с анимацией** (не на кнопки внизу).

## Настройки: продолжить с того места, где остановились

В меню слева откройте **«Настройки»**.

Раздел **«Действия при старте»** → переключатель **«Воспроизводить последнюю очередь»**.

- **Включено:** после следующего запуска приложение попытается продолжить не один трек, а **ту же очередь**, что была при выходе: альбом, избранное, популярные треки артиста, волна и т.п. Если вы слушали волну, подгрузка «дальше по волне» тоже восстанавливается.
- **Выключено:** при запуске по возможности продолжится только **последний один трек** с той позиции, где вы остановились (как раньше).

Переключатель можно менять в любой момент. Пока опция выключена, большой снимок очереди на диск не сохраняется.

## Установка

1. Откройте страницу **[Releases](https://github.com/virtusjit/sbzvuk-releases/releases)** этого репозитория.
2. Скачайте **`app-release.apk`** из релиза **1.2.2** (или [последнего](https://github.com/virtusjit/sbzvuk-releases/releases/latest)).
3. Скопируйте APK на ГУ и установите как обычное приложение.

Исходный код: [virtusjit/sbzvuk](https://github.com/virtusjit/sbzvuk).

## Если что-то не работает

- Проверьте интернет на автомобиле (при первом запуске приложение может подождать, пока сеть станет доступна).
- Проверьте, что токен введён и профиль в кнопке «Токен» отображается нормально (не горит ошибка).
- Если полноэкранная анимация пустая — откройте настройки Android для приложения и проверьте, что разрешение для визуализации/микрофона выдано (запрашивается при первом входе в полноэкранный режим).
- Перезапустите приложение.
